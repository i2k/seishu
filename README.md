# タイムトラベル 青洲文庫展 — 静的アーカイブ

図書館総合展2024「タイムトラベル 青洲文庫展 東京大学附属図書館における震災復興と図書疎開」の展示サイトの静的アーカイブです。
東京大学 文学部・人文社会系研究科 文化資源学研究室「文化資源としての書物」履修生が STUDIO（studio.design）で制作したサイトを、
STUDIO のプロジェクトがなくなっても閲覧できるよう、HTML・CSS・画像・フォント一式として保存しています。

- 取得元: STUDIO プレビュー（`preview.studio.site/live/NxqgGloVq1/`）
- 取得日: 2026-09-25
- ページ: トップ、震災復興（2〜9）、図書疎開（B1〜B4）、英語版（E1〜E4）

## アーカイブにあたっての変更

- JavaScript を除去し、スクロール出現アニメーションは表示完了状態で固定
- スライダー・カルーセルは CSS scroll-snap の横スクロールに置き換え（前後ボタン・自動再生なし）
- モーダル（写真・日誌）は CSS `:target` で開閉
- フォント（Google Fonts ほか）と画像はすべて `assets/` にローカル化
- `<title>` を全ページ「タイムトラベル 青洲文庫展」に統一
